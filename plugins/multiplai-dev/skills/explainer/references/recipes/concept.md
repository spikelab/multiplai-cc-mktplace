# Recipe: a concept or a plan

An idea the user is working on, a design not built yet, a way of working. The question is "What is X
and how would it work?".

## Gather

1. The user's own material: plans, notes, memory files, the conversation. These are the user's claims;
   the page says so ("planned", "proposed", `.chip.muted` "not built").
2. What already exists that the concept builds on: read it and cite it, so the page separates what runs
   today from what is proposed.
3. Ask the user one question when the order of the stages, or who the page is for, is not in the
   material. Do not invent either.

## Shape

- **Answer**: what the concept does for its user, in one sentence.
- **Picture**: built stages as `.node`, proposed ones as `.node.ghost`.
- **Worked example**: one case the concept handles, walked through as it would happen.
- **Deeper sections**: "What exists today" vs "What's proposed" (`.compare`); "Open questions" (only
  ones the material raises); "What's next" (`.road`).
- **Status words**: exists / proposed / open question.

Do not present a proposal as a fact, and do not fill an open question with an answer the user did not
give.
