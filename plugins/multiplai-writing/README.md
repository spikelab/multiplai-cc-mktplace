# multiplai-writing

Content-creation toolkit for Claude Code: **briefs, drafts, copy editing,
LinkedIn posts, and image prompts**. Part of the [`multiplai`](../../README.md)
marketplace.

## Installation

```
claude plugin marketplace add spikelab/multiplai-cc-mktplace
claude plugin install multiplai-writing@multiplai
```

## Skills

One skill, six modes:

| Mode | What it does |
|------|--------------|
| `brief` | Extract structure from a braindump into a content brief. |
| `cmd-brief` | Resolve commands in briefs. |
| `draft` | Transform a brief into a full draft. |
| `editor` | Copy edit for style and AI-tells. |
| `linkedin` | LinkedIn posts. |
| `imagen` | Image prompt generation. |

## Compatibility

Runs on vanilla Claude Code, any OS. Voice memory files are optional — the
skill asks when they're missing. See the
[compatibility matrix](../../README.md#compatibility-matrix).
